# 数据与来源

`original/` 是筛选后的原始文件快照，不在这里清洗或覆盖。`SOURCE_MANIFEST.csv` 逐项记录源路径、目标相对路径、筛选理由、文件大小、源 SHA256 与目标 SHA256。普通复制要求两者完全一致；notebook 和回测方法摘录另标转换方式。

## 正式研究输入

`original/formal/因子库_10.xlsx` 为新增离线流程的默认输入，共 1,784 行、date 加 153 个候选数值字段。目标 `二级5yYTM` 有 1,663 条非缺失观测，2019-01-02 至 2025-08-28。`09` 是旧版本；`factor_09` 已含处理结果与标签；`sig_二级5yYTM_ada` 是另一版信号，不混用样本。

153 个字段包括国债/国开/NCD/资本工具收益率、资金利率、互换、汇率、股票指数、政策利率、期限和跨品种利差、5/20 日均线等。永续债、股市、国债期货数据在此充当二级债的解释变量，保留这些列是必要的。

## AutoGluon 输入

`original/autogluon/merged_tier2.xlsx` 保留二级债实验的完整合并表，共 2,132 行、1,531 列。目标 `tier2__二级资本债_5Y` 有 1,655 条非缺失观测，2018-12-17 至 2025-10-16。日期前缀的重复候选列需要后续映射去重，不代表 1,530 个独立因子。

`market_inputs/` 为共享市场数据；`curve_inputs/` 为曲线和利差数据；`factor_snapshot/` 保留一个 20251029 快照及清单，避免多个日期副本膨胀。这些材料支持理解和后续重建，不能保证与合并表每列的历史版本完全一致。二级债历史模型与日频预测输出未在当前源目录中找到。

## 新生成数据

执行 `scripts/prepare_data.py --track formal` 或 `--track autogluon` 后生成：

- `processed/<track>/dataset.csv`：日期、标签日期、原始收益率、下一期收益率变化、统一标签、历史特征、分区。
- `source_columns.csv`：原表每个字段的非缺失量和缺失比例，方便逐列分工检查。
- `summary.json`：原表维度、有效目标期、周末观测数、分区起止/样本数/正类比例。

`label=1` 表示下一条可观测收益率下行或持平，0 表示上行；`target_date`、`next_yield_change_pctpoint` 是评价字段，绝对不能作为预测特征。`yield_pct` 的百分数单位按历史数据解释，仍需确认供应商定义。历史表没有完整的真实发布时刻、评级说明与版本修订信息，这些项不能通过整理文件推定。

源数据中有周末目标观测。当前流程不机械删除所有周末，也不将非缺失日期全部宣称为交易日；课程实证前需要对照原市场日历核验调休、估值日与缺测。离线基准预测的是下一条目标观测。

协作时用整个 project 文件夹或一个私有仓库同步原始输入一次；其他机器运行不依赖原来的 D 盘实习路径。`SOURCE_MANIFEST.csv` 的绝对源路径只作溯源。不要在多人之间另建不同的“最终版因子库”，更改输入须新增版本并记录原因。数据来源与对外共享授权没有在现有文件中得到确认，课程网站提交按要求说明实习来源；公开发布前先核实数据使用范围。
