# 二、AutoGluon 多品种框架与二级资本债策略

## 2.1 项目实际上包含两层

面试时务必区分：

### 第一层：AutoGluon 多品种研究与日频输出框架

代码对多个固定收益和跨资产目标做统一基线实验，包括：

- 国债期货基差：TS、TF、T、TL。
- 5 年期二级资本债收益率。
- FR007 互换：1 年、5 年。
- 10 年国债、10 年国开债收益率。
- 永续债和其他期限品种的探索。
- 黄金收盘价方向。

AutoGluon 的作用是快速比较多类表格模型、形成基准、保存模型并支持日频更新；它不是最终正式报告中所有模型的唯一训练器。

### 第二层：银行二级资本债正式研究

正式报告以 5 年期银行二级资本债收益率方向为目标，使用整理后的 153 个特征，系统比较逻辑回归、随机森林、LightGBM、XGBoost、Bagging、Stacking、GRU、LSTM 和 TCN，并对树模型、集成模型和深度学习模型进行贝叶斯调参。

推荐表述：

> AutoGluon 是我建立多品种基线和统一输出流程的工具；二级资本债报告则是在此基础上做的更严格单品种研究，包括特征清洗、模型对比、贝叶斯调参与回测。两者相关，但不能把 AutoGluon 的某一次输出直接等同于正式报告结果。

## 2.2 业务目标与经济含义

目标不是精确预测收益率点位，而是判断下一交易日 5 年期二级资本债到期收益率上行还是下行：

\[
\Delta y_{t+1}=y_{t+1}-y_t
\]

报告标签为：

- `Δy > 0`：记为 0，即收益率上行、债券价格偏弱。
- `Δy ≤ 0`：记为 1，即收益率下行或不变、债券价格偏强。

部分工程 notebook 使用 `-1/+1`：

- 收益率上行记为 `-1`。
- 收益率下行记为 `+1`。

二者经济意义相同，只是编码不同。面试时不要死背 0、1，直接说：

> 我统一按债券价格方向解释：收益率下降是做多信号，收益率上升是减仓或空头信号。历史 notebook 存在 0/1 与 ±1 两种编码，生产化时应固定标签字典。

为什么选二级资本债：

- 它既受无风险利率、资金面和曲线影响，又受银行资本工具风险溢价影响。
- 发行人以大型银行、股份行和主要城农商行为主，主体维度相对标准化。
- 相对普通信用债，违约事件噪声较少，方向变化更集中地反映利率、流动性、供需和风险偏好。
- 但它仍有次级受偿、减记/转股、赎回预期和流动性风险，纯时间序列模型不能替代主体及条款研究。

## 2.3 数据流程

代码流程可以拆成五层：

1. `data.py` 通过 Wind 拉取原始数据，按类别增量保存。
2. `factor.py` 从本地原始数据计算传统因子。
3. `new_factor.py` 对各类曲线建立统一代码—字段映射，计算同类期限利差和跨类利差。
4. notebook 将因子文件按日期内连接，列名前加来源前缀，构造目标标签并按时间切分。
5. `update_output.py` 更新因子、加载保存的 AutoGluon 模型、生成预测并按目标输出。

一版全量合并结果为约 2,122 行、771 列。这里的 771 是工程合并阶段的候选字段总数，包含带日期前缀的重复版本；正式二级资本债报告使用的是清理后的 153 个特征。面试时应说“候选库较宽，正式模型 153 个特征”，不要说最终模型稳定使用 770 个独立因子。

## 2.4 因子体系全解

### 2.4.1 收益率曲线与期限结构

原始曲线覆盖国债、国开债、AAA+ 企业债、中短期票据、同业存单以及活跃国债收益率。主要构造：

| 因子 | 示例 | 经济含义 |
|---|---|---|
| 国债期限利差 | 10Y−1Y、10Y−3Y、10Y−5Y、30Y−10Y | 增长、通胀、政策预期与期限溢价 |
| 国开期限利差 | 国开10Y−5Y、国开10Y−1Y | 政金债曲线形态和配置需求 |
| 国开—国债利差 | 国开10Y−国债10Y、5Y、1Y | 税收、流动性、机构偏好与相对价值 |
| 信用利差 | AAA+中票−同期限国开 | 信用风险、流动性与信用配置情绪 |
| 活跃券—曲线利差 | 10Y活跃券−10Y国债曲线 | 活跃券流动性溢价及估值偏差 |
| 活跃券期限利差 | 10Y活跃券−3Y/5Y/7Y活跃券 | 交易型曲线形态 |

代码中某些字段用“国债−信用债”而不是通常的“信用债−国债”。符号相反不影响模型学习，但解释时必须先说明方向。规范做法是统一写成风险资产收益率减基准收益率，使“利差扩大”为正。

为什么与二级资本债有关：二级资本债定价可以粗略拆成无风险曲线、银行普通债信用利差、资本工具次级/条款溢价和流动性溢价。上述曲线与利差因子分别刻画这些共同成分。

### 2.4.2 目标品种与相邻品种

`new_factor.py` 拉取：

- 二级资本债 1Y、2Y、3Y、5Y、7Y、10Y。
- 银行永续债 1Y、2Y、3Y、5Y、7Y、10Y。
- 同业存单 1Y。

可构造：

- 二级资本债自身曲线斜率。
- 永续债−二级资本债的资本工具相对利差。
- 二级资本债−国开债的信用及条款溢价。
- 二级资本债不同期限的联动。

直观逻辑：永续债风险层级更高、久期与赎回不确定性更强；两类资本债之间的利差变化能反映银行资本工具风险偏好。国开债则提供较高流动性的政策性金融债基准。

### 2.4.3 资金面与货币市场

原始字段包括 R001、R007、DR001、DR007、FR001、FR007、3M SHIBOR 和 1Y SHIBOR。派生因子包括：

- 各利率 5 日移动平均：平滑短期资金噪声。
- 各利率 5 日标准差：衡量资金波动。
- 上述均值和波动在过去 1 年的历史分位：判断当前资金是否相对偏贵、偏紧或异常波动。
- R007−R001：期限资金压力。
- SHIBOR 1Y−FR007 IRS 1Y：银行信用/期限资金与互换预期差。

资金宽松通常通过降低杠杆成本、提高配置需求来压低中短端收益率和信用利差；跨月、跨季、缴税和政府债发行会造成短期扰动。因此均值、波动和历史分位比单日绝对值更有信息。

### 2.4.4 利率互换与衍生品

FR007 IRS 使用 6M、9M、1Y、2Y、5Y，SHIBOR IRS 使用 1Y、2Y、3Y、5Y。相关因子包括：

- FR007 IRS 5Y−1Y：互换曲线斜率。
- FR007 IRS 1Y−9M：近端政策预期。
- 国债5Y−FR007 IRS5Y：互换利差。
- SHIBOR IRS 与 FR007 IRS 同期限差。

互换价格含市场对未来资金利率的预期，并受银行负债、套保和机构交易影响。它能为现券曲线提供独立于现金债供需的信息。

### 2.4.5 国债期货行情与技术特征

对 TS、TF、T、TL 的 OHLCV 计算：

- 5/10/20 日 SMA、TRIMA。
- ROC、CMO、Williams %R、KDJ。
- Momentum、OBV、ADI、ATR。
- 典型价 `VWAP=(H+L+C)/3` 及 `VWAP/CLOSE`。
- K 线实体和影线：`KMID=(C−O)/O`、`KLEN=(H−L)/O`、`KMID2=(C−O)/(H−L)`、`KUP2`、`KLOW2`、`KSFT2`。

这些因子刻画期货市场的趋势、日内方向、波动和量价行为。国债期货通常比某些信用估值曲线反应更快，因此可以作为下一日利率方向的领先或同步信息，但必须保证使用的是决策时点已收盘的数据。

### 2.4.6 国债期货跨期价差

对 TS、TF、T、TL 计算活跃合约 VWAP 减次活跃合约 VWAP。它反映：

- 市场对交割期、资金和曲线的预期。
- 主力换月与持仓迁移。
- 期限结构和相对拥挤。

严格研究还应处理连续合约拼接、交割期、CTD 与转换因子，单纯主力−次主力价格差只能视为代理因子。

### 2.4.7 权益与风险偏好

万得全 A、上证 50、中证 500、中证 1000分别计算 1 日和约 30 日涨幅。逻辑是：

- 权益上涨、风险偏好增强可能带来债券止盈和资金搬家。
- 小盘与大盘分化可反映风险偏好的强弱和政策交易结构。
- 股债关系会随通胀、政策和流动性状态变化，不能预设永久负相关。

### 2.4.8 宏观与政策

代码中的字段包括 GDP 不变价同比及当季值、美元指数、美元兑人民币即期汇率、1 年 MLF、7 天 OMO 数量。低频宏观数据通过前值填充到日频。

这里最大的技术要点不是 `ffill` 本身，而是发布日期：季度 GDP 不能从季度第一天起填充，必须从真实发布日期之后才进入模型；修订值也要使用 point-in-time 版本。否则即使代码没有 `shift(-1)`，仍可能发生宏观数据泄露。

### 2.4.9 日历因子

包括月份、日期、星期、是否 15 日、是否 20 日和是否交易日，用来代理缴税、跨月、缴准和固定政策时点。日历因子可解释，但很容易样本内偶然有效，应通过多年和滚动窗口验证。

## 2.5 数据清洗与样本切分

正式报告流程：

- 样本起点：2019-01-02。
- 训练与验证：2019-01-02 至 2024-05-13。
- 独立测试：2024-05-14 至 2025-08-27。
- 大致按 8:2 的时间顺序切分。
- 剔除节假日。
- 用 Z-score 标记异常值。
- 用线性插值补缺失值。
- 主要对特征做一阶差分，缓解非平稳和训练/测试分布漂移。

一阶差分：

\[
x_t^{diff}=x_t-x_{t-1}
\]

优点是削弱趋势和量纲影响；缺点是丢失绝对水平信息。更稳健的设计可同时保留“水平、变化、历史分位”，并让验证决定增量价值。

对异常和缺失值的正确面试回答：

> 我不会把所有异常值都当错误。先区分数据故障和真实市场冲击；只有数据故障才替换。线性插值适合短缺口，不适合宏观发布和长时间停牌。更严格的版本会按字段定义不同处理规则，并增加缺失指示变量。

## 2.6 模型结构与选择理由

### 基准模型

- 逻辑回归：检验线性可分性和系数方向，作为可解释基线。
- 随机森林：通过 bootstrap 与随机特征子集降低单棵树方差。

### Boosting 模型

- LightGBM：逐轮拟合残差，适合非线性表格特征，训练效率高。
- XGBoost：带正则的梯度提升树，对非线性和交互较强。

### 集成模型

- Bagging-LGBM：对子样本重复训练 LightGBM，再加权融合，主要降低方差。
- Stacking：第一层由 LightGBM、SVM、逻辑回归等异质模型输出概率，第二层元学习器学习组合权重。元学习器的输入必须是 out-of-fold 预测，而不是基模型对自己训练样本的拟合值。

### 深度学习模型

- GRU：两层 GRU + attention + layer normalization + dropout + 全连接层。
- LSTM：两层 LSTM + attention + layer normalization + dropout + 全连接层。
- TCN：一维卷积 + temporal block + layer normalization + dropout + 全连接层。

模型超参数使用贝叶斯优化，每类约 100 次搜索。报告中的主要搜索区间：

| 模型 | 深度/隐藏维度 | 学习器/层数 | 学习率 | 其他 |
|---|---|---|---|---|
| Random Forest | max depth 3—40 | 200—1500 棵树 | — | 叶节点最小样本 1—100 |
| XGBoost | depth 3—12 | 200—1500 | 0.001—0.3 | min child weight 0.01—20 |
| LightGBM | 叶数/复杂度 16—512 | 200—2000 | 0.001—0.2 | 叶节点最小样本 5—200 |
| GRU | hidden 32—256 | 2—4 层 | 1e-5—5e-3 | 窗口 5—30 |
| LSTM | hidden 32—320 | 2—4 层 | 1e-5—5e-3 | 窗口 5—20 |
| TCN | hidden 64—320 | 2—6 层 | 1e-5—5e-3 | 窗口 5—30 |

阈值不固定为 0.5，而是在验证集扫描候选概率阈值，以 F1 或 recall 等目标选择，再冻结后用于测试集。阈值不能在测试集上重选。

## 2.7 AutoGluon 在代码里做了什么

典型流程是：

```text
宽因子表 → 构造下一日标签 → 时间顺序 80/20 切分
        → TabularPredictor.fit(presets='best')
        → evaluate(test_data) → 保存模型
        → 日频更新字段 → 按训练 schema 对齐 → load + predict
```

AutoGluon 会根据数据自动训练若干可用的表格模型，并通过 bagging/stacking 或 weighted ensemble 组合。项目价值是：

- 快速形成多模型基准，判断品种是否有可预测性。
- 减少逐个模型手工写训练代码。
- 自动处理部分缺失值和字段类型。
- 保存完整预测器，支持日频加载。

但它不会自动解决金融时间序列最关键的问题：

- 默认内部验证未必尊重时间顺序。
- 不知道宏观数据的真实发布时间。
- 不知道标签正负号的交易含义。
- 不知道成本、久期和执行限制。

因此正确定位是“研究加速器”，不是“自动生产交易策略”。

## 2.8 从预测到仓位和收益

对于收益率方向模型，经济信号应统一成：

- 预测收益率下降：做多或维持债券久期。
- 预测收益率上升：减久期；若工具允许，可用国债期货空头对冲。

正式报告回测是“不做空”的持仓逻辑，因此模型主要通过减少错误做多来改善回撤。实际落地可定义概率仓位：

\[
position_t=clip\left(\frac{p_t-p_0}{b},0,1\right)
\]

其中 `p_t` 是收益率下行概率，`p_0` 是开仓阈值，`b` 控制仓位斜率。比硬分类更能利用置信度，也更适合加交易成本和风险预算。

债券策略收益不能简单等同于收益率变化。更接近交易的近似为：

\[
r_{t+1}\approx carry+roll-down-D_{mod}\Delta y+\frac12 Convexity(\Delta y)^2-spread\ cost-funding\ cost
\]

若使用指数或估值收益序列，则必须解释基准究竟包含票息、净价还是全价。

| 模型 | F1 | AUC | Accuracy | Precision | Recall |
|---|---:|---:|---:|---:|---:|
| Random Forest | 0.584 | 0.603 | 0.579 | 0.505 | 0.697 |
| LightGBM | 0.714 | 0.652 | 0.565 | 0.565 | 0.968 |
| XGBoost | 0.686 | 0.616 | 0.539 | 0.555 | 0.899 |
| Bagging | 0.726 | 0.643 | 0.598 | 0.612 | 0.892 |
| Stacking | 0.744 | 0.621 | 0.610 | 0.611 | 0.951 |
| GRU | 0.458 | 0.552 | 0.532 | 0.429 | 0.492 |
| LSTM | 0.463 | 0.503 | 0.560 | 0.492 | 0.438 |
| TCN | 0.389 | 0.432 | 0.441 | 0.348 | 0.442 |

测试回测期 2024-05-15 至 2025-08-27：

- 策略累计收益约 7.78%，基准约 4.92%。
- 超额约 2.87%。
- 策略年化约 4.17%，基准约 2.64%。
- 年化波动约 1.89%，最大回撤约 1.13%。
- Sharpe 约 1.28，信息比率约 1.04。

如何解释：集成模型 F1 和准确率更均衡；LightGBM recall 极高但 precision 较低，说明它较积极地预测正类。AUC 与 F1 排序不同，是因为 AUC 衡量所有阈值下的排序能力，F1 是某一阈值下 precision 与 recall 的折中。

为什么深度学习较弱：有效日频样本只有几千、单资产噪声高、状态变化快；树模型对表格非线性和中小样本更友好。不能推广成“深度学习不适合金融”，它在多资产横截面、高频或文本数据中可能更有优势。

## 2.10 多品种 AutoGluon 探索结果如何解释

保存的 notebook 中，某些版本大致出现：

- 10 年国债：测试准确率约 69.8%，AUC 约 0.753。
- 10 年国开债：准确率约 65.1%，AUC 约 0.724。
- 二级资本债的一次早期 AutoGluon 测试：准确率约 50.2%，且类别不平衡。
- 黄金：准确率约 56.7%，AUC 约 0.48—0.50，排序能力接近随机。

这不是矛盾，而是说明：

- 不同版本的数据截止日、标签和因子表不同。
- AutoGluon 基线不保证每个资产有效。
- 利率债与资金、曲线因子的联系更直接；黄金的主要驱动还包括实际利率、美元、地缘和海外持仓。
- 验证集很好但独立测试显著下降，通常提示过拟合、状态切换或数据口径问题。

## 2.11 代码层风险与修复顺序

### 严重风险 1：前视收益因子

`factor.py` 有候选函数：

```python
res = x.shift(-period) / x - 1
```

它把未来收益写到当前行。如果该列进入训练，就构成直接信息泄露。应改为：

```python
res = x / x.shift(period) - 1
```

修复后必须从因子生成开始完全重跑，不能只改代码后继续引用旧模型。

### 严重风险 2：AutoGluon 内部验证

外层 80/20 虽按时间切分，但 AutoGluon 的内部 bagging/stacking 如果随机折叠，会让较晚训练样本预测较早折中的验证样本。应提供按时间的 folds，或在每个 walk-forward 窗口内单独训练并只预测下一个窗口。

### 重要风险 3：标签与字段版本

`update_output.py` 有 `inverse=True`，注释说明部分品种训练时标签方向忘记统一；文件列名还带训练日期前缀。应建立：

- `label_map.yaml`：每个品种的正类经济含义。
- 固定 feature schema 和数据类型。
- 模型版本、训练截止日、特征版本与 Git commit。

### 重要风险 4：日期和数据更新

代码曾将 `YYYYMMDD` 字符串转整数再 `+1`，月末会产生非法日期。应使用 `pd.Timestamp + BDay(1)`。合并时内连接可能因为单个数据源缺失而丢掉整行，也应明确缺失策略。

### 研究风险 5：特征太宽、重复和解释性

全量表 771 列对约 2,122 个样本维度过高，且存在日期前缀重复列。需先去重、按经济组做消融、用滚动稳定性而非一次 permutation importance 筛选，并关注多重共线性。

## 2.12 AutoGluon 项目三分钟面试回答

> 这个项目分两层。第一层是多品种 AutoGluon 框架，我把国债、国开债、二级资本债、FR007、国债期货基差和黄金等目标统一到日频因子表，用时间顺序 80/20 切分，快速比较表格模型并保存预测器，再通过更新脚本做每日字段对齐和输出。第二层是正式的 5 年期银行二级资本债研究，它使用清理后的 153 个特征，样本从 2019 年开始，独立测试期是 2024 年 5 月到 2025 年 8 月。  
>  
> 因子分为六类：国债和国开债曲线及信用利差、R/DR/FR和SHIBOR资金因子、IRS及国债期货衍生品因子、二级资本债和永续债相对价值、权益风险偏好、宏观与日历。多数连续特征做一阶差分，同时保留期限结构和历史分位，目标是预测下一日二级资本债收益率方向；收益率下降对应债券做多。  
>  
> 模型上比较逻辑回归、随机森林、LightGBM、XGBoost、Bagging、Stacking 和三类时序神经网络，并在验证集进行贝叶斯调参与阈值选择。样本外 Stacking 的 F1 约 0.74、准确率约 0.61；回测年化约 4.17%、最大回撤约 1.13%。树模型和集成优于深度学习，主要因为日频单序列样本有限。  
>  
> 我现在不会只强调结果。复盘中我发现一个候选函数用了负向 shift，AutoGluon 内部验证也需要改成时间感知。这些都要求从数据血缘开始修复并完全重训。若投入实际使用，我会统一标签、做 walk-forward、按信息发布日期处理宏观数据，并把概率转为受 DV01 和成本约束的仓位。AutoGluon 对我而言是建立基线和工程化的工具，不是替代研究判断的黑盒。

## 2.13 AutoGluon 常见追问

**问：为什么预测方向，不回归收益率变动？**

> 收益率日变动噪声大，回归误差很容易被极端日主导；方向更直接对应加减久期。但方向也丢失幅度信息，所以后续可以做两阶段模型：先预测方向，再预测条件幅度，或直接预测概率并按期望收益/风险定仓。

**问：为什么 LightGBM recall 很高但准确率一般？**

> 阈值优化偏向识别正类，加上类别分布不均衡，模型可能频繁报正类，从而获得高 recall、较低 precision。应看混淆矩阵，并把误报与漏报转成实际交易损失，而不是只追 recall。

**问：特征重要性最高的国债 30Y 变化说明什么？**

> 它可能说明长端利率变化代表久期情绪和曲线整体冲击，但 permutation importance 在相关特征中会不稳定，也不代表因果。我会做删组实验和多窗口稳定性检查后再解释。

**问：模型如何落到交易？**

> 对可交易组合先估算基准持仓和 DV01，再根据收益率下行概率调整目标 DV01；信号弱时不交易，信号强时分级加仓。国债期货用于对冲系统性久期，二级资本债现券仍要受流动性、主体额度和条款约束。
