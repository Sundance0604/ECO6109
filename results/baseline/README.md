# 已运行的离线基准

本次使用 `因子库_10` 原始目标的非缺失观测，统一正类为下一条可观测收益率下行或持平。测试信号日期为 2024-05-14 至 2025-08-27，共 323 条；不等同于旧报告的 344 条已处理样本。

| 基准 | 预测正确数 | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|---|
| 训练期多数类 | 183/323 | 0.566563 | 0.566563 | 1.000000 | 0.723320 |
| 当期方向延续 | 190/323 | 0.588235 | 0.635870 | 0.639344 | 0.637602 |

多数类一直预测下行或持平；方向延续将当前观测日相对前一观测日的方向延续一期。训练、验证、测试边界已清除跨区标签。这里只报告分类，未估算收益或成本。正式输入中有 46 条周末目标观测，尚需对照市场日历确认；当前研究入口没有把它们武断认定为正常交易日或错误数据。

`test_predictions.csv` 是逐日核验依据；`metrics.json` 是程序计算结果；`environment.json` 是本次环境；`verification.json` 记录独立 CSV 计数、文件哈希、标签和边界检查。独立重算得到的 Accuracy 与 F1 均与主流程一致。多数类 F1 达到 0.72，说明仅拿高 F1 作为复杂模型有效性的证据不充分。

实际使用的整理运行环境为打包 Python，安装环境与组员电脑可能不同。新逻辑回归和 AutoGluon 入口尚未运行，旧模型和回测也未重现。重新运行会覆盖本目录的基准文件；如果计划保存多次实验，请先另存运行目录。
