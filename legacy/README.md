# 历史研究材料使用说明

`formal/` 保留三个二级资本债研究 notebook 原件，包含多轮清洗、模型和调参版本以及保存输出。`yield_backtest_excerpt.py` 从原 `data_train_backtest.py` 只提取通用的信号、持仓、久期/票息近似和绩效方法，移除 Wind 初始化与永续债批量运行；该方法摘录仍含旧输入路径与日期假设，供研究复盘，不是报告结果的精确复现程序。

`autogluon/` 保留原始共享数据、因子、训练和更新脚本，以及两份二级债 notebook。`tier2_excerpts.ipynb` 是从大 notebook 提取的二级债实验；新增说明标明原单元索引，原代码和保存输出没有改写。`训练示例.ipynb` 是未经修正的历史模板。

正常协作从根目录 `scripts/` 启动。这些历史脚本存在个人绝对路径、导入外部数据终端、标签不一致、旧 pandas 写法，以及数据清理函数等问题。不要把它们当作新的统一流水线。要借用某个方法时，复制到自己的工作文件并记录原文件和单元位置，修正后重新验证。

共享脚本保留了多目标映射，这是二级债因子框架的依赖；独立黄金、国债期货择时、基差模型和永续债专用训练产物没有搬入。具体来源和摘录方式以 `data/SOURCE_MANIFEST.csv` 为准。
